# gamma
gamma - это мини приложение для покупки и управления rw и пользователями


## Проверка конвертации Platega

Бот раз в 12 часов читает общий баланс USDT через существующий API
`/balance/all` (настройки `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`).
Браузер, логин в кабинет и таблица конвертаций для этого не нужны.
Первый успешный запрос сохраняет исходный баланс без уведомления.
При увеличении приходит сообщение: прирост, старый и новый баланс.
При уменьшении или неизменном балансе сообщение не отправляется, новое
значение сохраняется для следующего сравнения. Состояние хранится в БД
и переживает перезапуск. Ошибочный ответ не обнуляет сохранённый баланс;
повтор — через час, предупреждение — не чаще раза в сутки.

Сравнивается общий USDT, включая средства в процессе выплаты, чтобы
возврат замороженных средств не выглядел как конвертация. Разница — чистый
прирост: завершённые выводы между проверками уменьшают её. Это не точная
сумма всех конвертаций за период при наличии других движений средств.
После перехода со старого парсера первая проверка начинает новое сравнение.

Проверка доступа без уведомлений и записи состояния:
`python gamma/manage.py platega_conversions_check`.
Изменение не требует новой миграции; после обновления перезапустите бот.
